# Virani & Sorathia wedding website

Shazeena Virani weds Shahzad Sorathia · 29th – 30th January 2027 · Denver, Colorado

Live at https://shahzadsorathia.github.io/VS-Wedding/

A single-page wedding website: an opening invitation card with a tassel and doors, our story, the three celebrations (Pithi / Sangeet, Nikkah, Reception), travel and stay with a map of Denver, and the RSVP link.

The website is hosted on GitHub Pages, and RSVPs are handled through Google Apps Script.
